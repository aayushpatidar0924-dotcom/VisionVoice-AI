# 🚀 VisionVoice AI

VisionVoice AI is a Python-based desktop assistant that combines Computer Vision, Voice Recognition, and Desktop Automation into a single real-time system.

The project allows users to control their computer using hand gestures and voice commands.

---

# ✨ Features

## 🖐 Hand Gesture Control
- Cursor movement using index finger
- Left click
- Double click
- Right click
- Drag & Drop
- Scroll control

---

## 🎤 Voice Commands
- Open YouTube
- Open ChatGPT
- Open Chrome
- Open VS Code
- Google Search
- Type text using voice
- Browser tab controls

---

## 🖥 GUI Features
- Modern PyQt5 interface
- Always-on-top floating assistant
- Camera preview toggle
- Voice ON/OFF
- Gesture ON/OFF

---

# 🧠 Technologies Used

- Python
- OpenCV
- MediaPipe
- PyQt5
- SpeechRecognition
- PyAutoGUI
